A program that writes one letter — **H**, for *hangry* — to `/output/entry.txt`. Entered on make.fun's "One Letter for Your Day" bounty ($5 in USDC): one letter stands for the word that describes your day, and a judge picks the letter whose hidden word feels more vivid, funnier, or truer. Hangry — hungry plus angry, lunch skipped, every small annoyance landing twice as hard — is vivid, funny, and true, and H is its own initial rather than the obvious pick.

## Run it

```sh
node main.ts
```
